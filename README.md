# Primer PR Práctica

Este repositorio es un espacio de práctica para aprender el flujo de trabajo de Git y GitHub:
crear una rama, hacer un cambio, y abrir un Pull Request.

## Objetivo

Este repo sirve para experimentar con:

- Clonar un repositorio
- Crear ramas
- Hacer commits
- Abrir y revisar Pull Requests

Es un proyecto de aprendizaje, no un proyecto de produccion.
